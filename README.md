# Chill Autocorrect for Obsidian

A desktop-only autocorrect plugin for Obsidian. When you press space after typing a misspelt word, it uses the first suggestion from your OS's native spellchecker. It protects words saved in Obsidian’s custom dictionary. Windows and macOS can suggest different corrections.


# How to use

Make a folder in your community plugins folder called "chill-autocorrect".
Copy and paste the manifest.json + main.js in.
Refresh in Obsidian and enable the plugin.
Then just type normally...
