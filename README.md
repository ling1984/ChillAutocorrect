# Chill Autocorrect for Obsidian

A desktop-only autocorrect plugin for Obsidian. 

When you press space after misspelling a word, it uses the first suggestion from your OS's native spellchecker. 
Backspace to undo.

It protects words saved in Obsidian’s custom dictionary. Windows and macOS can suggest different corrections.


## How to use
1. Make a folder in your community plugins folder called "chill-autocorrect".
2. Copy and paste the manifest.json + main.js in.
3. Refresh in Obsidian and enable the plugin.
4. Then just type normally...
